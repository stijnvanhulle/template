Open a GitHub issue for `$ARGUMENTS`, following the `issue` skill.

Search the open and closed issues first, and comment on a match instead of opening a duplicate.
Use the matching form in `.github/ISSUE_TEMPLATE/`. Read the valid values with `gh label list`,
`list_issue_types`, and `list_issue_fields`, then set the type, the labels, and the Priority
and Effort fields.

Report the issue URL, and which field values you guessed.
