---

Open a GitHub issue for `$ARGUMENTS`, following the `issue` skill.

1. Search the open and closed issues first, and comment on the match instead of opening a
   duplicate.
2. Pick the matching form in `.github/ISSUE_TEMPLATE/`, and answer every required field.
3. Read the valid values with `gh label list`, `list_issue_types`, and `list_issue_fields`.
4. Set the type, the labels, and the Priority, Effort, Start date, and Target date fields.

Report the issue URL, and which field values you guessed.
